# SIMBIOXIS Rivals Tournament

## Overview
A React + TypeScript + Vite frontend for a Marvel Rivals tournament website (SIMBIOXIS U.N.D.I. Cup). It features pages for home, information, teams, brackets, and contact. Styled with Tailwind CSS (CDN), Google Fonts, and FontAwesome.

## Recent Changes
- 2026-02-24: Initial Replit setup. Configured Vite to use port 5000, allowed all hosts for proxy compatibility, removed conflicting importmap from index.html. Configured static deployment.

## Project Architecture
- **Framework**: React 18 + TypeScript + Vite 5
- **Styling**: Tailwind CSS (CDN), custom fonts (Orbitron, Montserrat, Anton), FontAwesome icons
- **Routing**: react-router-dom v6
- **Entry**: index.html -> index.tsx -> App.tsx
- **Pages**: pages/ (HomePage, InformacionPage, EquiposPage, BracketPage, ContactoPage)
- **Components**: components/ (Navbar, Hero, Button, Footer)
- **Build output**: dist/
- **Deployment**: Static (Vite build)
